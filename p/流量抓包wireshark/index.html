流量抓包（Wireshark）

2026-03-08

一、什么是流量抓包

流量抓包（Packet Capture）是指通过工具捕获网络中传输的数据包，并对其进行分析。

常见用途：

  • 网络故障排查
  • 网络安全分析
  • CTF比赛取证
  • 协议学习
  • 发现异常流量

常见抓包工具：

  • Wireshark
  • tcpdump
  • Burp Suite
  • Fiddler

二、Wireshark简介

Wireshark 是最常用的网络抓包分析工具。

特点：

  • 免费开源
  • 支持 Windows / Linux / macOS
  • 支持上千种协议解析
  • 可视化数据包分析

官方网站：

https://www.wireshark.org/

三、Wireshark安装

Windows

  1. 进入官网 https://www.wireshark.org/download.html
  2. 下载 Windows Installer
  3. 安装时注意勾选
1

Npcap

Npcap 用于抓取网络数据包。

Linux（Ubuntu）

安装命令：

1
2

sudo apt update
sudo apt install wireshark

运行：

1

wireshark

四、Wireshark界面介绍

Wireshark界面主要分为三部分：

1 数据包列表（Packet List）

显示所有抓到的数据包。

包含：

  • No. 包编号
  • Time 时间
  • Source 源地址
  • Destination 目标地址
  • Protocol 协议
  • Length 数据长度
  • Info 信息

2 数据包详情（Packet Details）

显示协议解析，例如：

1
2
3
4
5

Frame
Ethernet
IP
TCP
HTTP

3 数据包原始数据（Packet Bytes）

显示十六进制数据：

1

0000  00 1a 2b 3c 4d 5e ...

五、开始抓包

步骤：

  1. 打开 Wireshark
  2. 选择网卡

常见网卡：

  • Ethernet（有线）
  • Wi-Fi（无线）
  1. 双击网卡开始抓包

六、停止抓包

点击：

1

红色方块按钮

即可停止抓包。

在安全分析中，可以重点关注：

1 异常IP

  • 未知外网IP
  • 频繁通信的IP

2 异常协议

  • Modbus

  • FTP
  • 未知协议

3 异常端口

2

九、Follow Stream（跟踪流）

Wireshark可以重组通信数据。

步骤：

  1. 右键数据包
  2. 选择
1

Follow → TCP Stream

或

1

Follow → UDP Stream

作用：

  • 还原完整通信
  • 查看明文数据
  • 找 flag

十二、Modbus协议

Modbus 是工业控制系统（ICS）常见协议。

常见端口：

1

502

在抓包中可能看到：

1

Modbus/TCP

攻击者可能：

  • 读取寄存器
  • 修改设备状态
  • 伪造指令

1
2

十四、实战分析流程

  1. 打开 pcap 文件
  2. 查看协议统计
1

Statistics → Protocol Hierarchy
  1. 查异常协议
  2. 查异常IP
  3. Follow TCP Stream
  4. 搜索 flag
  5. 导出文件
