CTF Web 学习系统方案

2026-03-22

一、 基础知识储备

在动手做题前，必须掌握 Web 运作的底层逻辑。

1. 网络协议

  • HTTP 协议：请求方法（GET, POST, PUT, OPTIONS）、请求头/响应头含义、状态码（200, 302, 403, 500）、Cookie 与 Session 机制。
  • HTTPS：基础的加密传输原理。

2. 前端技术

  • HTML：能看懂表单（Form）、隐藏输入框（Hidden）。
  • JavaScript：理解 DOM 树，掌握常用的前端加解密函数（Base64, MD5），会使用浏览器控制台（F12）。

3. 后端环境

  • PHP (核心)：CTF Web 的主力语言。重点看：变量覆盖、弱类型比较（== vs ===）、反序列化（serialize/unserialize）。
  • 数据库：MySQL 语法，重点是查询语句（SELECT）、联合查询（UNION）、注释符（#, -- ）。
  • Linux：常用命令（ls, cat, find）、文件读取权限、Web 容器（Apache/Nginx）的基础配置。

二、 核心漏洞详解

这是 CTF Web 的加分项，需逐一攻克原理并能手写 Payload。

1. 注入类

  • SQL 注入：从联合查询（Union）开始，进阶到盲注（布尔/时间）、报错注入、堆叠注入。
  • 命令执行 (RCE)：在服务器上执行系统命令。学习如何绕过空格（${IFS}）、黑名单（拼接、编码）。

2. 文件操作

  • 文件上传：绕过后缀检查（.php5, .phtml）、内容检查（GIF89a）、配置文件包含（.htaccess）。
  • 文件包含 (LFI)：读取系统敏感文件（/etc/passwd）。必须掌握 PHP 伪协议：php://filter 读源码，php://input 写命令。

3. 逻辑与高级漏洞

  • 反序列化：理解魔法函数触发链。
  • SSRF (服务端请求伪造)：利用服务器去请求它内部的网络。
  • XXE (XML 实体注入)：通过 XML 读文件。
  • 变量覆盖：如 extract()、$$ 导致的变量篡改。

三、 必备工具集

工具是辅助，原理是基础。建议先手动复现，再使用工具。

  1. Burp Suite (核心)：
    • Proxy：拦截并修改数据包。
    • Repeater：重发数据包，调试 Payload。
    • Intruder：爆破目录、文件名或参数。
  2. 浏览器插件：
    • HackBar：快速构造 GET/POST 请求。
    • Proxy SwitchyOmega：快速切换代理（配合 Burp 使用）。
  3. 脚本/扫描器：
    • Python (必学)：用来编写自动化的盲注脚本。
    • Dirsearch：扫描网站目录和隐藏文件（如 .git, .svn, .DS_Store）。
    • SQLmap：自动化 SQL 注入工具（建议原理搞懂后再用）。

四、 实战练习路径

不要只看书，直接上平台做题。

  1. 入门级：
    • Bugku / CTFshow：题目很细，适合练习单一漏洞点（如“PHP特性”、“SQL注入”专项）。
  2. 进阶级：
    • 攻防世界 (XCTF)：题目综合性更强，接近真实比赛。
    • BUUCTF：收录了国内各大比赛的原题，含金量极高。
  3. 复现要求：
    • 做不出题时，搜索“题目名 + Writeup”。
    • 重点看思路：别人是怎么发现这个漏洞点的？
    • 必须复现：关掉题解，自己把 Flag 跑出来。

五、 学习建议

  • 多读源码：遇到给源码的题是好事，学会搜索敏感函数（如 eval(), system(), include(), unserialize()）。
  • 记笔记：建立自己的 Payload 库，比如“绕过空格的 10 种方法”。
  • 坚持：Web 的知识点很碎，前期挫败感很强，复现完 50 道典型题后会有质变。
